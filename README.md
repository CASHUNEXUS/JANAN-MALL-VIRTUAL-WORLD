# JANAN MALL | TABRIZ — Virtual World

A mobile-friendly interactive mall concept prototype.

## Run locally
Open `index.html` in a modern browser. To publish it, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

## Controls
- Desktop: WASD / arrow keys to walk; E to enter a nearby store.
- Mobile: on-screen directional buttons; ENTER opens a nearby store.
- Use **Back to the Mall** to leave a store.

## Current prototype scope
Original Canvas-based 2.5D concept (not yet a production 3D game): stylized multi-level atrium, scrolling world view, four discoverable storefronts, separate store-interior scenes, sample catalogues and mobile controls. Prices and products are placeholders.
